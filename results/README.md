# Main-experiment result tables

- `table1_headline_results.csv`: headline FNSPID results for twelve models at three VaR levels.
- `table2_dm_hac.csv`: DM-HAC test statistics and two-sided p-values.
- `table18_dependence_inference.csv`: pooled breach-rate estimates, moving-block intervals, and DQ results.
- `table19_daily_summary.csv`: pooled breach rates, daily dispersion, stress maxima, and lag-1 autocorrelations.

The tables follow the definitions and reporting precision in the manuscript. See `docs/manuscript_mapping.md` for table locations.
