# Released data

- `test_date_index.csv`: the 986 eligible forecast dates used by the revised temporal diagnostics. The initial migration omits date-level eligible-firm counts because the complete authoritative daily model export has not yet been added.
- `covid_daily_breach_95.csv`: daily 95% cross-sectional breach rates for the 20 crash-window forecast dates reported in the revision.
- `covid_mae_distribution.csv`: the realized 20-day maximum-adverse-excursion summary for the same 81,001 eligible origins.

These files are derived evaluation artifacts. They do not redistribute copyrighted news text or original market records.
